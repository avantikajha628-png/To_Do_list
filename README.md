# To-Do List Android App

A simple Android application for creating, managing, and tracking daily tasks.

## 📱 About the Project

The To-Do List app helps users organize their daily tasks in one place. Users can add and manage their tasks through a simple and user-friendly interface.

## ✨ Features

- Add new tasks
- View tasks
- Manage daily tasks
- Simple and user-friendly interface
- Lightweight Android application

## 🛠️ Technologies Used

- Kotlin
- Android Studio
- Android SDK
- Gradle

## 🚀 How to Run

### Prerequisites

Before running the project, make sure you have:

- Android Studio installed
- Android SDK installed
- An Android device or Android Emulator
- Internet connection for the first Gradle sync
